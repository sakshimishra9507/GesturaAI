# Project Overview
## Problem
Keyboard, mouse and touch interfaces are not always ideal for contactless or accessibility-focused interaction.

## Solution
Gestura AI uses webcam video, MediaPipe hand landmarks, normalized landmark features and a trained ML classifier to recognize gestures in real time. Results can be converted to text/speech and mapped to restricted, safe actions.

## Objectives
1. Detect hands in real time.
2. Extract robust features.
3. Train and evaluate ML models.
4. Recognize gestures.
5. Provide dashboard/history.
6. Build an extensible foundation for accessibility and edge deployment.
