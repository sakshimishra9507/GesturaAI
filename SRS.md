# Software Requirements Specification
## Functional
Webcam access, hand detection, feature extraction, prediction, confidence display, history storage and optional action/speech modules.

## Non-functional
Low latency, modular Python code, reproducible training, local-first processing and clear error handling.

## Hardware
Minimum: modern dual-core CPU, 4 GB RAM, webcam. Recommended: 8 GB+ RAM and 720p webcam.

## Software
Python 3.10+, OpenCV, MediaPipe, scikit-learn, Flask and SQLite.
